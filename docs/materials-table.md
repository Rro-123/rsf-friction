# 内置材质参数表

> 本文件是 rsf.js 内置材质参数表（`RSF.materials`）的独立说明文档，由《使用指南》第四节拆分而来。机器可读版本见 [`../materials/materials.json`](../materials/materials.json)，两者保持一致。

---

## ⚠️ 数据性质（重要）

- **摩擦系数属于「接触对」，不是单一材质**：每条记录都明确标注接触面 `材质A-材质B`（含干/湿条件）。**岩石数据为同种岩石对磨实验值**（如花岗岩-花岗岩）。
- **库仑 `μ`（动摩擦）/ `μ_s`（静摩擦）**：常见工程材料**干摩擦**的教科书 / 工程手册**量级参考值**，来源包括 Serway & Jewett《Physics for Scientists and Engineers》摩擦系数表、Engineering ToolBox、《机械设计手册》等。
- **RSF 参数（`μ₀ / a / b / Dc / V0`）**：**岩石摩擦实验**（Dieterich 1979；Ruina 1983；Marone 1998 等）的**典型量级**，并非特定岩石样品的标定值。
- **⚠️ 库仑 `μ/μ_s` 是「常数双态」简化，不代表这些材料真的无速度依赖或不会粘滑**：`computeFriction` 对库仑模式仅按「静止→`μ_s`、滑动→`μ_k`」处理，不含速度/状态演化，所以**模拟不出粘滑**。但实际低速干摩擦下，**凡 `μ_s > μ_k`（静摩擦 > 动摩擦）的材料**（如橡胶-钢、冰-钢、木材、皮革、铅等）都**会表现出粘滑（stick-slip）**，这正是库仑简化无法复现的物理现象；要建模粘滑需 RSF 参数（`μ₀/a/b/Dc/V0` 且 `a−b<0`）。库中岩石类已内置 RSF 参数；工程材料多为库仑参考值，如需模拟某材料粘滑请用实测/标定值或查阅专用文献（如弹性体摩擦的 rate-and-state 研究）。
- 摩擦系数受表面粗糙度、润滑、湿度、温度、氧化膜等影响极大，不同来源可相差 **±20% 甚至数倍**。**正式仿真/实验请务必用实测或标定值替换这些参考值。**

## 怎么读这张表

本表以「接触材质」为中心展开：**每个材质一个小节，列出它与所有已收录材质的接触对数据**（按涉及接触对数量排序，组合最多的材质排最前）。表中没有出现的组合表示该接触对暂无收录数据。注意：

- **键名（key）规则**：`computeFriction` 传入的键名即程序接口，**其形式反映是否为同种材料自接触**——
  - **自配对（材料A 与 材料A 相互接触，如 钢-钢、花岗岩-花岗岩、铜-铜）用单名键**：`steel`、`granite`、`copper`；
  - **异材质（两个不同材料，如 铝-钢、聚甲醛-钢）用「主材质_副材质」成对键名**：`aluminum_steel`、`pom_steel`；
  - 特例：`stainless_steel`（不锈钢-不锈钢）单名中的下划线属于**材质名本身**（不锈钢 = stainless steel），并非成对连接符；
  - 工况后缀：湿摩擦条目标 `_wet`（如 `rubber_concrete_wet` = 橡胶-混凝土（湿））。
- **`name` 字段是人类可读的接触面对描述**（如 "铝-钢（干）"），用于展示；**键名才是传给 API 的值**，二者不要混淆。
- 接触对是**对称的**（铝-钢 与 钢-铝 相同），同一接触对可能出现在涉及的两个材质小节中，方便按任一材质查询。

## 分类说明

| 类别 | 包含材质 | 计算模式 |
|---|---|---|
| **岩石类** `rock` | 花岗岩、辉长岩、蛇纹岩、滑石等（同种岩石对磨） | 含 RSF 参数，`computeFriction` 自动走 **RSF 模式**（含速度依赖） |
| **金属类** `metal` | 钢、铜、黄铜、钛、不锈钢、金等 | 仅库仑 `μ/μ_s`，走 **库仑模式**（与速度无关） |
| **聚合物类** `polymer` | 橡胶、PTFE、尼龙、POM、PVC、PEEK 等 | 仅库仑 `μ/μ_s`，走 **库仑模式** |
| **其他非金属** `other` | 玻璃、木材、混凝土、冰、石墨、沥青路面、皮革等 | 仅库仑 `μ/μ_s`，走 **库仑模式** |
