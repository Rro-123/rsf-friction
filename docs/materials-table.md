# 内置材质参数表

> 本文件是 rsf.js 内置材质参数表（`RSF.materials`）的独立说明文档，由《使用指南》第四节拆分而来。机器可读版本见 [`../materials/materials.json`](../materials/materials.json)，两者保持一致。

---

## ⚠️ 数据性质（重要）

- **摩擦系数属于「接触对」，不是单一材质**：每条记录都明确标注接触面 `材质A-材质B`（含干/湿条件）。**岩石数据为同种岩石对磨实验值**（如花岗岩-花岗岩）。
- **库仑 `μ`（动摩擦）/ `μ_s`（静摩擦）**：常见工程材料**干摩擦**的教科书 / 工程手册**量级参考值**，来源包括 Serway & Jewett《Physics for Scientists and Engineers》摩擦系数表、Engineering ToolBox、机械设计手册等。
- **RSF 参数（`μ₀ / a / b / Dc / V0`）**：**岩石摩擦实验**（Dieterich 1979；Ruina 1983；Marone 1998 等）的**典型量级**，并非特定岩石样品的标定值。
- 摩擦系数受表面粗糙度、润滑、湿度、温度、氧化膜等影响极大，不同来源可相差 **±20% 甚至数倍**。**正式仿真/实验请务必用实测或标定值替换这些参考值。**

---

## 怎么读这张表

本表以「接触材质」为中心展开：**每个材质一个小节，列出它与所有已收录材质的接触对数据**。表中没有出现的组合表示该接触对暂无收录数据。注意：

- 接触对是**对称的**（铝-钢 与 钢-铝 相同），同一接触对可能出现在涉及的两个材质小节中，方便按任一材质查询；
- `computeFriction` 传入的**键名**（如 `steel`、`aluminum`）与 `name`（接触对名）不同：键名是程序接口，name 是人类可读的接触面对描述；
- 配对对象不明的条目（如仅写"聚丙烯(PP)"而未注明与谁摩擦）已从表中移除，避免误导。

## 分类说明

| 类别 | 包含材质 | 计算模式 |
|---|---|---|
| **岩石类** `rock` | 花岗岩、辉长岩、蛇纹岩、滑石等（同种岩石对磨） | 含 RSF 参数，`computeFriction` 自动走 **RSF 模式**（含速度依赖） |
| **金属类** `metal` | 钢、铜、黄铜、钛、不锈钢、金等 | 仅库仑 `μ/μ_s`，走 **库仑模式**（与速度无关） |
| **聚合物类** `polymer` | 橡胶（对混凝土）、PTFE（对钢）、尼龙、聚乙烯（对钢） | 仅库仑 `μ/μ_s`，走 **库仑模式** |
| **其他非金属** `other` | 玻璃、木材、混凝土、冰、石墨、沥青路面等 | 仅库仑 `μ/μ_s`，走 **库仑模式** |
